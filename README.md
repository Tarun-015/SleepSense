
# 💤 SleepSense — Sleep Health Analysis & Prediction

An interactive Machine Learning application that explores sleep health patterns, analyzes lifestyle-related factors, and predicts sleep-related outcomes using data-driven models.

SleepSense combines exploratory data analysis, feature engineering, machine learning, and interactive visualization to make sleep-related insights easier to understand.

---

## 🚀 Project Overview

SleepSense is an end-to-end Data Science project focused on understanding sleep patterns and identifying relationships between lifestyle characteristics and sleep health.

The project involves:
- Exploratory Data Analysis (EDA)
- Data preprocessing and feature engineering
- Machine Learning model development
- Model comparison and performance evaluation
- Interactive visualization through Streamlit
- Prediction outputs and analytical insights

---

## 🎯 Key Features

- **Exploratory Data Analysis:** Investigating sleep patterns and relevant lifestyle variables.
- **Feature Engineering:** Developing meaningful features for machine learning.
- **Machine Learning:** Implementing and evaluating predictive models.
- **Model Comparison:** Comparing model performance using evaluation results.
- **Interactive Dashboard:** Exploring sleep-related insights through a Streamlit interface.
- **Prediction Analysis:** Viewing model-generated predictions and outputs.

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/Tarun-015/SleepSense.git
cd SleepSense
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the environment

**Windows:**

```powershell
venv\Scripts\activate
```

**Mac/Linux:**

```bash
source venv/bin/activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the application

```bash
streamlit run app.py
```
